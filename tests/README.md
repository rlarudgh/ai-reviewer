# Tests

면접 프롬프트 품질 검증을 위한 테스트 구조.

## 테스트 방법

프롬프트 품질은 `/interview-tester` 스킬을 통해 자동 검증합니다.

```bash
# 프론트엔드 트랙 QA
/interview-tester frontend

# 서버 트랙 QA
/interview-tester server
```

## 수동 테스트 체크리스트

새 프롬프트나 수정 후 확인:

- [ ] 질문이 중복되지 않는지 (8-12개 모두 고유한 주제)
- [ ] 난이도가 점진적으로 상승하는지
- [ ] 꼬리질문이 이전 답변과 논리적으로 연결되는지
- [ ] "끝" 입력 시 평가 리포트가 정상 생성되는지
- [ ] 평가 점수가 rubric 기준과 일치하는지
- [ ] 골든셋(`docs/examples/`)과 비교 시 품질 저하가 없는지
