## 1. 개요 (Overview)

### 1.1 제품 설명

AI Reviewer는 Claude Code Skill 기반 인터랙티브 기술 면접 도구입니다. 경력자 대상으로 심화 질문, 꼬리질문, 실무 경험, 상황 대처 질문을 진행하고 종합 평가를 제공합니다.

### 1.2 목표

- 기술 면접의 일관성과 품질 향상
- 면접관의 부담 감소 및 면접 준비 시간 단축
- 후보자의 실무 역량을 체계적으로 평가
- 반복 가능하고 객관적인 평가 체계 제공

### 1.3 대상 사용자

- **Primary**: 기술 면접을 진행하는 시니어 엔지니어, 팀 리드, CTO
- **Secondary**: 기술 면접을 준비하는 경력 개발자 (자가 테스트용)

## 4. 시스템 아키텍처

### 4.1 구성 요소

```
User (Claude Code CLI)
  │
  ▼
/interview [track]
  │
  ├──► SKILL.md (메타데이터 & 워크플로우)
  │
  ├──► prompts/interviewer-system.md (면접관 페르소나)
  │
  ├──► prompts/{track}.md (트랙별 주제 가이드)
  │         ├── frontend.md
  │         ├── app.md
  │         └── server.md
  │
  ├──► prompts/evaluator.md (평가 에이전트)
  │
  └──► rubric.md (평가 기준표)
```

### 4.2 데이터 흐름

1. **Setup Phase**: SKILL.md 읽기 → 트랙 매핑 → 해당 프롬프트 로드
2. **Interview Phase**: interviewer-system.md + {track}.md 기반 질문 생성 및 피드백
3. **Evaluation Phase**: evaluator.md + rubric.md 기반 대화 기록 분석 및 리포트 생성

## 5. 평가 기준

### 5.1 평가 항목 및 가중치

| 항목         | 가중치 | 설명                                               |
| ------------ | ------ | -------------------------------------------------- |
| 기술 이해도  | 40%    | 개념 정확성, 깊이, 트렌드 이해, 트레이드오프 인식  |
| 문제 해결력  | 30%    | 체계적 접근법, 논리적 사고, 엣지 케이스, 대안 검토 |
| 실무 경험    | 15%    | 구체적 사례, 의사결정 과정, 실패와 학습            |
| 커뮤니케이션 | 15%    | 명확성, 구조, 용어 사용, 질문 의도 파악            |

### 5.2 점수 척도

- **9-10점**: Expert 수준
- **7-8점**: Proficient 수준
- **4-6점**: Competent 수준
- **1-3점**: Developing 수준

자세한 기준은 `rubric.md` 참고

## 6. 사용자 시나리오

### 6.1 시나리오 1: 기본 면접 진행

1. 사용자가 프로젝트 디렉토리에서 Claude Code 실행
2. `/interview frontend` 입력
3. Claude가 프롬프트 로드 후 면접 시작
4. 8-12개 질문 진행 (기술 → 꼬리질문 → 실무 → 상황)
5. 사용자가 "평가해줘" 입력
6. 종합 평가 리포트 출력

### 6.2 시나리오 2: 트랙 선택 안내

1. 사용자가 `/interview` 입력 (인자 없음)
2. 사용 가능한 트랙 목록과 설명 표시
3. 사용자가 원하는 트랙 입력 후 면접 시작

### 6.3 시나리오 3: 중간 종료

1. 면접 진행 중 사용자가 "그만" 입력
2. 지금까지의 답변으로 종합 평가 리포트 생성
3. 완전한 면접보다는 부분 평가로 안내

#### v1.3.0 상세 계획: 경력 수준별 면접 레벨

**배경**: 현재는 "경력자"를 전제로 한 시니어 중심 면접만 지원. 신입/주니어 대상 면접이 필요함.

**변경 파일**:

- `SKILL.md`: 명령어에 레벨 인자 추가 또는 시작 시 질문 (`/interview frontend junior`)
- `interviewer-system.md`: 레벨별 페르소나 및 질문 전략 분기
- `prompts/{track}.md`: 레벨별 Topic Guide 추가
- `evaluator.md`: 레벨 정보를 받아 해당 레벨 기준으로 평가
- `rubric.md`: **가장 큰 작업** — 레벨별 별도 평가 기준 필요 (같은 1-10점이라도 기준 완전 상이)

**주요 과제**:

- 같은 7점이라도 "신입의 7점"과 "시니어의 7점" 기준을 분리해야 함
- 레벨별 실무 경험 질문 유무 결정 (신입은 코딩 테스트/기본 개념 중심)
- 페르소나 조정 (시니어 면접관 vs 멘토링 중심 면접관)
