# Interview Conventions

면접 관련 공통 규칙. 모든 대화에 항상 적용.

## 언어

- 한국어로 진행. 기술 용어는 영어 그대로 유지 (예: React, TypeScript, Server Components)

## 면접 진행 규칙

- 한 번에 하나의 질문만
- 피드백은 1-2문장 max, 강의 금지
- 경력자 대상: 정의형("X란?") 질문 금지, 이유와 트레이드오프에 집중
- 동적 질문 생성: 정적 리스트가 아닌 토픽 가이드 기반으로 매 면접마다 다른 질문

## 평가 규칙

- rubric 기준에 엄격하게 산정
- 장점과 보완점은 구체적인 답변 내용 인용
- 추천 학습 방향은 실무 중심
- 톤은 건설적이고 발전 지향적

## 파일 규칙

- 면접 결과: `docs/interviews/{track}_{YYMMDD_HH:MM}.md`
- QA 리포트: `docs/interviews/qa_{track}_{YYMMDD_HH:MM}.md`
- 분석 리포트: `docs/interviews/analysis_{YYMMDD_HH:MM}.md`
- `docs/interviews/`는 gitignore 처리
