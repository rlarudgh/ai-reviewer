여러 면접 기록을 분석해 메타 분석 리포트를 생성합니다.

## 인자: $ARGUMENTS (선택: frontend | app | server | --last N)

## 실행 단계

1. `docs/interviews/` 디렉토리의 모든 markdown 파일 읽기
2. 트랙 필터가 지정된 경우 해당 트랙만 필터링
3. `--last N` 인자가 있는 경우 최근 N개만 분석
4. 각 파일에서 파싱: 트랙명, 총점, 세부 점수, 강점, 약점, 추천 학습 방향

## 분석 항목

### 1. 점수 분포
- 카테고리별 평균 점수
- 점수 분산 (일관성 지표)
- 최고/최저 득점 영역

### 2. 강점 패턴
- 가장 자주 언급된 강점
- 트랙별 강점 비교

### 3. 약점 패턴
- 가장 자주 언급된 약점
- 위험 약점 (점수 < 5)
- 면접 간 반복되는 테마

### 4. 개선 추이 (3건 이상 시)
- 시간별 점수 추이
- 이전 약점 개선 여부
- 새롭게 나타난 약점

## 출력 포맷

```markdown
## Interview Meta-Analysis Report

**분석 기간:** [period]
**분석 면접 수:** X건

### Overall Summary
| 지표 | 평균 | 최고 | 최저 | 표준편차 |
|------|------|------|------|----------|
| 총점 | X.X  | X.X  | X.X  | X.X      |

### 반복되는 강점 (Top 5)
1. ...

### 반복되는 약점 (Top 5)
1. ...

### 개선 추이
[이전 약점 개선 추적]

### 트랙별 비교
[트랙 간 점수 차이 분석]

### 종합 권장사항
[우선 개선 영역과 구체적 액션 아이템]
```

## 저장

리포트를 대화창에 출력하고 `docs/interviews/analysis_{YYMMDD_HH:MM}.md`에 저장.

## 규칙

- 최소 1건 이상의 면접 기록 필요
- 3건 미만이면 개선 추이 섹션 생략
- 한국어로 작성
- 실행 가능한 인사이트에 집중 (단순 데이터 나열 금지)
- rubric 기준과 비교하여 위험 약점 식별
